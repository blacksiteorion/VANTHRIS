# VANTHRIS

**Android WhatsApp Digital Forensics Toolkit**

VANTHRIS is an educational digital forensics project focused on exploring Android-based WhatsApp data analysis, evidence handling, and forensic investigation techniques.

The project is being developed as an independent cybersecurity learning and portfolio initiative under Blacksite Orion Group.

## Project Status

Early development.

## Objectives

- Explore Android forensic data structures.
- Study WhatsApp data storage and organization.
- Develop forensic analysis capabilities.
- Support authorized examination of user-owned data.
- Document findings and investigation workflows.

## Development

More technical documentation, features, and installation instructions will be added as development progresses.

## Disclaimer

VANTHRIS is intended strictly for educational purposes and authorized digital forensic investigations. Users are responsible for ensuring they have appropriate permission to examine any data.
