# Security Policy

## Supported Versions

This project is currently in early development. Security updates and patches will be applied to the `main` branch.

| Version | Supported          |
| ------- | ------------------ |
| Main    | :white_check_mark: |

## Responsible Use

VANTHRIS is an Android Digital Forensics tool intended **strictly for authorized examinations, educational purposes, and security research**. 

- **Do not** use this tool on devices you do not own or have explicit, documented permission to examine.
- **Do not** use this tool to bypass Android security controls, application authentication, or encryption.
- **Do not** upload any sensitive forensic evidence or personal data acquired using this tool to this repository or any public platform.

## Reporting a Vulnerability or Abuse Concern

If you discover a security vulnerability in VANTHRIS, or if you have concerns about the potential misuse of this tool, please report it responsibly.

**Please do not open a public issue for security vulnerabilities.** Instead, contact the maintainer directly:
- **Maintainer:** Ujjwal Singh Tomar
- **Organization:** Blacksite Orion Group
- **Contact:** Open a private security advisory on GitHub (via the "Security" tab of this repository).

We are committed to responsible development and will address legitimate security and abuse concerns promptly.
